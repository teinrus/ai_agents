# Память

Отдельный слой. Класс агента память не содержит. Слой не знает про домен роли.

## Разделы

- `run` — только этот прогон. Чтение чужого `run` закрыто портом.
- `agent` — прогоны одной роли.
- `department` — роли отдела.

Обращение: раздел + ключ. Операции порта: `put`, `get`, `search`, `list`.

В запись кладётся итог решения. Сырой документ внешней системы в память как замену журналу не писать.

Новый вид раздела — регистрация в платформе, не новая ветка агента. Новое хранилище — другая реализация `MemoryBackend`.

## Реализации

- Тесты: `MockMemory`.
- Первое боевое хранилище этапа реализации: SQLite.
- Распределённое хранилище — общий каталог файлов, этап 4. Тот же порт `put / get / search / list`.

Агент строку подключения не открывает. Backend внедряет runtime.

## Как расширять

Меняется адаптер или регистрируется раздел. Сигнатуры `put / get / search / list` и имена трёх базовых разделов не ломаются.

Не хранить в памяти секреты, токены подтверждения и тела, которые запрещены на уровне INFO в шине.

## Готово, когда

- Два прогона одной роли не читают `run` друг друга.
- `agent` виден следующему прогону той же роли.
- Замена mock на SQLite не меняет код роли.
