# Безопасность

Безопасность платформы — политика и границы данных, не фильтр в промпте.

## Секреты

Только окружение. Не в репозитории, не в каталоге моделей, не в скилле роли, не в событии, не в ответе API.

Ядро обязано стартовать на моках без секретов внешней системы. Секрет нужен лишь адаптеру, который реально вызывает эту систему.

## Действия

Потолок риска задаёт платформа и сужает роль. Модель, скилл и клиентский payload потолок не поднимают.

`destructive` закрыт, пока нет отдельного платформенного решения.

Подтверждение одноразовое: `run_id` + хеш существенных аргументов. `correlation_id` приходит от клиента и для привязки токена не годится. Токен не годится для другого прогона и для других аргументов.

## Журнал и память

DEBUG с сырым промптом выключен вне локальной среды.

Редакция обязательна для ключей, паролей, `Authorization`, тел внешних документов на INFO.

Память хранит итог решения, не секрет и не одноразовый токен.

## Граница роли

Роль не получает чужой раздел `run` и не вызывает инструмент вне своего списка.

Ошибка политики — `deny` или ожидание подтверждения, не необработанное исключение, которое обходит шлюз.

## Готово, когда

- Тест доказывает `deny` для действия выше потолка и для `destructive`.
- Тест доказывает, что секрет из окружения не появляется в ленте INFO.
- В коде нет второго пути вызова инструмента «для отладки».
